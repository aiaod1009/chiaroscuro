# Chiaroscuro

Chiaroscuro 是一个以摄影作品管理、影像叙事和 AI 辅助创作为核心的全栈项目。它把“拍摄、整理、展示、分析、生成”串成一条完整流程：前端负责呈现作品、地图足迹、照片详情与 AI 创作界面，后端负责照片、作品集、AI、对象存储和数据库。

这个项目更像一个摄影师的数字工作台：既能浏览作品，也能管理素材，还能让 AI 参与标题、配文和影像解读。

## 项目定位

- 面向摄影作品整理与展示场景。
- 支持照片从上传、归档到作品集管理的完整链路。
- 通过足迹地图和专题页面，把照片内容从“文件”变成“故事”。
- 通过 AI 页面，把照片的标题、配文和叙事风格进一步结构化。

## 核心功能

### 照片管理

- 浏览草稿、详情和单张照片信息。
- 编辑照片标题与配文。
- 支持照片移动、复制、移出作品集。
- 支持删除照片并同步清理云端资源。

### 作品集管理

- 创建、更新、删除作品集。
- 查看作品集详情和关联照片。
- 自动补全作品集封面，适合做专题展示。

### 足迹与地图

- 按地区聚合照片数据。
- 用地图方式展示拍摄轨迹和地域分布。
- 适合从“拍了什么”过渡到“在哪拍的、怎么拍的”。

### AI 影像叙事

- 提供构图分析和影像解读。
- 支持诗意、叙事、极简等生成风格。
- 支持多轮迭代优化，让生成结果更接近目标表达。
- 支持恢复历史会话，便于继续编辑。

### 云端上传

- 接入腾讯云 COS 进行图片存储。
- 支持草稿上传与成片上传两类流程。
- 配合 EXIF 解析保留照片拍摄信息。

## 技术栈

- 前端：Vue 3、Vue Router、Vite、Axios、Three.js
- 后端：Node.js、Express、Mongoose、MongoDB
- 存储与上传：Tencent COS、Multer
- 图像与数据处理：EXIF 解析、TopoJSON、D3 Geo

## 本地运行

### 1. 启动 MongoDB

后端依赖本地 MongoDB，请先确认数据库服务已启动。

### 2. 启动后端服务

```bash
cd server
npm install
npm run dev
```

后端默认监听 `http://localhost:3000`。

### 3. 启动前端服务

```bash
cd web
npm install
npm run dev
```

Vite 启动后会输出本地访问地址，通常是 `http://localhost:5173`。

## 环境变量

后端会读取 `.env` 文件中的配置。常见字段如下：

- `MONGO_URI`：MongoDB 连接地址
- `PORT`：后端服务端口，默认 `3000`
- `COS_SECRET_ID`：腾讯云 COS SecretId
- `COS_SECRET_KEY`：腾讯云 COS SecretKey

如果你要启用上传、对象存储或 AI 能力，请根据实际业务把对应配置补齐。

## 页面一览

- `/`：首页，大图封面与精选作品入口。
- `/archive`：归档页，集中展示摄影内容。
- `/console`：控制台，偏管理操作和内容整理。
- `/footprints`：足迹地图，展示拍摄地域分布。
- `/notes`：AI 影像叙事页，用于分析和生成文案。
- `/gallery-detail/:id`：画廊详情页。
- `/photo-detail/:id`：照片详情页。
- `/photo-desk/:mapCode`：地区照片列表页。
- `/postcards`：明信片展示页。
- `/console/work/:id`：作品集详情页。

## 页面风格说明

前端不是单纯的后台表单，而是偏展示型的摄影站点：

- 首页使用大图背景和选集卡片，强调视觉入口。
- 导航栏采用固定悬浮式设计，适合在浏览过程中持续切换模块。
- Notes 页面强调 AI 创作与手动编辑双模式，适合做内容生产。
- 地图与画廊相关页面偏向数据可视化和故事化呈现。

## 后端接口概览

后端接口主要分为四组：

- `api/photos`：照片查询、编辑、上传、删除。
- `api/works`：作品集管理。
- `api/ai`：AI 生成、会话查询和分析。
- `api/cos`：对象存储相关能力。

详细接口说明可以直接查看 [server/API.md](server/API.md)。

## 使用建议

- 第一次运行时，先确认 MongoDB 和 `.env` 配置都正确。
- 如果页面能打开但数据为空，优先检查后端服务和接口返回。
