看来你不需要那种复杂的 3D 浮雕或角色跳出来的动效，纯粹只需要**画面像纸张一样带有弧度地翻过去**，并且能把每一页替换成你自己的照片，对吧？

如果去除掉复杂的 3D 元素，只保留核心的**纸张弯曲翻页效果**，在 Three.js 中实现起来会简单非常多。我们只需要把重心放在**网格弯曲的数学公式（Shader）**和**照片纹理贴图**上。

以下是为你量身定制的精简版实现方案：

---

## 核心实现步骤

### 1. 准备照片作为纹理 (Textures)

你需要把你的照片加载为 Three.js 的纹理。因为书页有正反面，如果你想翻过去看到另一张照片，你需要准备“正面照片”和“背面照片”。

```javascript
const textureLoader = new THREE.TextureLoader();
// 加载你的照片
const imgPage1 = textureLoader.load('your_photo_1.jpg'); // 第一页正面
const imgPage2 = textureLoader.load('your_photo_2.jpg'); // 第一页背面（翻过来后看到的）

```

### 2. 创建高密度网格与旋转中心

和之前提到的一样，照片（平面）必须有足够的横向分段，否则无法变弯。

```javascript
// 宽度分段设为 32，高度设为 1 即可（因为主要是横向弯曲）
const geometry = new THREE.PlaneGeometry(width, height, 32, 1);

// 关键：把平面的中心点移到左边缘，这样它就会绕着左侧“书脊”旋转
geometry.translate(width / 2, 0, 0);

```

### 3. 用自定义 Shader 实现纸张弯曲

这是实现视频中那种“中间凸起、两边平滑”的纸张质感的核心。我们可以通过修改 `Vertex Shader`（顶点着色器），让顶点的 $Z$ 轴（前后深度）根据当前翻页的角度动态弯曲。

这里有一个精简的数学模型：**弯曲程度由一个正弦函数决定，在翻到一半（90度）时弯曲最大。**

```javascript
// 自定义材质，允许我们在顶点着色器中加入弯曲逻辑
const pageMaterial = new THREE.MeshStandardMaterial({
    map: imgPage1,
    side: THREE.DoubleSide // 双面可见
});

// 在编译材质前注入弯曲公式
pageMaterial.onBeforeCompile = (shader) => {
    // 引入一个全局变量 progress (0 到 1)，表示翻页进度
    shader.uniforms.progress = { value: 0 };
    
    // 修改顶点着色器
    shader.vertexShader = `
        uniform float progress;
    ` + shader.vertexShader;

    shader.vertexShader = shader.vertexShader.replace(
        '#include <begin_vertex>',
        `
        #include <begin_vertex>
        
        // 计算弯曲弧度：利用正弦曲线，让书页在翻到中间时 $Z$ 轴凸起
        // position.x 是顶点在书页上的横坐标
        float bend = sin(progress * 3.14159) * sin((position.x / ${width.toFixed(1)}) * 3.14159);
        
        // 赋予 Z 轴深度，实现纸张空气阻力的弯曲感（0.2 为弯曲幅度，可调）
        transformed.z += bend * ${width.toFixed(1)} * 0.2; 
        `
    );
    
    // 挂载到材质上方便后面在动画中修改
    pageMaterial.userData.shader = shader;
};

```

### 4. 配合 GSAP 驱动翻页动画

使用动画库（如 GSAP）同时改变**书页的旋转角度**和 **Shader 里的弯曲进度**：

```javascript
const pageMesh = new THREE.Mesh(geometry, pageMaterial);
scene.add(pageMesh);

// 触发翻页
gsap.to(pageMesh.rotation, {
    y: -Math.PI, // 绕 Y 轴翻转 180 度
    duration: 1.2,
    ease: "power1.inOut"
});

// 同步让 Shader 变弯再变平
if (pageMaterial.userData.shader) {
    gsap.to(pageMaterial.userData.shader.uniforms.progress, {
        value: 1, // 从 0 到 1 再回到 0 的映射，可以用 keyframes 优化
        duration: 1.2,
        ease: "power1.inOut"
    });
}

```

## 更简单的替代方案：现成插件

如果你不想自己写底层的数学公式和 Shader，这里有两个非常契合你需求的开源项目，你可以直接拿来放照片：

1. **`page-flip` (by Volumental / Alexey Krasnoperov)**
* 虽然它是纯 2D Canvas 实现，但它通过极高超的数学模拟，做出了**完全以假乱真的 3D 纸张弯曲和阴影效果**。
* **优点**：不需要懂 Three.js 和 WebGL，直接丢大图（照片）进去就能跑，性能极好，支持手机端拖拽。


2. **GitHub 搜索：`threejs-page-flip**`
* 社区有很多现成的“3D电子书/相册”模板，其核心逻辑就是在一本建好的 3D 书籍模型上轮流替换图片纹理。你只需要下载他们的源码，把 `TextureLoader` 路径换成你的照片即可。



**总结建议**：
如果只是为了做个人相册或展示照片，强烈建议优先尝试 **`page-flip`** 库，它能用最少的代码帮你实现视频里 90% 以上的纸张翻动质感。
